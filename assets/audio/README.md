# Property soundtracks (placeholders)

Every file here is a **placeholder**: a computer voice (Windows "Hazel")
over a generated music bed. Replace each one with the real recording,
keeping the same file name, and the site picks it up with no code change.

Each property file: about 2 s of music, the intro spoken softly (female
voice, Kenyan English accent), then 30–40 s of the property's theme music
fading out. MP3, 96–128 kbps, under 1 MB.

Keep the licence for every track and voice recording (AI-generated music
needs a paid plan that allows commercial use).

To change an intro line shown to visitors, edit `audioIntro` for that
property in `assets/js/properties-data.js`.
